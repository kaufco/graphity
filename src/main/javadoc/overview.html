Graph analysis algorithms for Java on a compact, immutable graph: connected components, bridges and articulation points, topological order, cycle and edge classification, reachability and breadth-first distances, tree ancestry, dominators and loops, and quotient graphs.

Built for compiler and analysis pipelines - syntax trees, control- and data-flow graphs, dependency graphs. Every algorithm runs without recursion and returns a typed result with follow-up queries. Data on nodes and edges stays in arrays you own, indexed by node ID or edge index.

The library comes as modules released together at the same version: {@code graphity-core} with the graph, the builder and every algorithm that applies to any directed graph, {@code graphity-controlflow} with the analyses that need the concepts of control flow, {@code graphity-dot} with a writer for DOT and {@code graphity-mermaid} with a writer for Mermaid.
