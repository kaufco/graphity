Graphity is a Java graph library which keeps graphs in a compact, immutable form and provides algorithms on top of it, such as strongly and weakly connected components, bridges and articulation points, topological order and levels, cycle detection and edge classification, breadth-first distances and reachability, lowest common ancestors, dominators, loop nesting and condensed graphs.

Every algorithm returns a typed, immutable result with follow-up queries, and runs without recursion, so deep graphs do not overflow the call stack. Data on nodes and edges stays in your own arrays, indexed by node ID or edge index, and every transformation tells you how to carry them along. The graph itself stores only structure: 4 bytes per node and per edge, in a compressed sparse row (CSR) layout, which is where speed and footprint come from.

Where to start

The nodes of a {@link com.kobayami.graphity.Graph} are the {@code int} IDs {@code 0..nodeCount()-1}, and its edges are numbered by edge index {@code 0..edgeCount()-1}, ordered by source and then by target. {@link com.kobayami.graphity.GraphBuilder} builds a graph from edges in any order. The algorithms are not methods of the graph but static methods: {@code of} on a class named after the algorithm, such as {@link com.kobayami.graphity.TopOrder#of(com.kobayami.graphity.Graph) TopOrder.of} and {@link com.kobayami.graphity.Dominators#of(com.kobayami.graphity.BiAdjacentGraph, int) Dominators.of}; the methods of {@link com.kobayami.graphity.Components} for the components; and those of {@link com.kobayami.graphity.Graphs} for the rest, such as {@link com.kobayami.graphity.Graphs#findCycle(com.kobayami.graphity.Graph) Graphs.findCycle}.

A {@code Graph} holds the out-nodes of every node. {@link com.kobayami.graphity.BiAdjacentGraph#of(com.kobayami.graphity.Graph) BiAdjacentGraph.of} adds the in-nodes. The algorithms that need them, such as {@link com.kobayami.graphity.Dominators} and {@link com.kobayami.graphity.Components#biconnectivityOf(com.kobayami.graphity.BiAdjacentGraph) Components.biconnectivityOf}, take a {@code BiAdjacentGraph}: build it once and pass it to all of them.

Contracts

Every method states its contract: what it returns and throws, whether a result is a view or a copy, in which order the results come where that matters, and its cost in time and memory. Three rules hold across the whole API:

  • No parameter, return value or element in the API is {@code null} unless its type is annotated {@code @Nullable}.
  • Graphs, mappings, partitions and the results of the algorithms are immutable and safe to share between threads. The builder, the traversers and the writers are mutable and not safe to share between threads.
  • A node ID, an edge index or any other ID or position outside its range throws {@link java.lang.IndexOutOfBoundsException}; any other invalid argument throws {@link java.lang.IllegalArgumentException}.
