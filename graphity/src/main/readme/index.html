graphity

This artifact has no code of its own. It depends on the Graphity modules graphity-core, graphity-controlflow, graphity-dot and graphity-mermaid, all at the version of this artifact, so that one dependency brings in the whole library.

The API documentation of all modules is at https://kaufco.github.io/graphity/. Each module also comes with its own sources jar and Javadoc jar.
